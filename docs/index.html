Why it exists · 02

The system should stay out of the way.

MiniPad is built around the small moments that compound: launching a tool, changing a track, reaching an app on another display, or cleaning up software you no longer need.

< 25 MBTarget memory footprint

01 / LAYOUT

Adaptive by default

Grid density and container sizing respond to the available display instead of forcing one fixed launcher geometry.

02 / MOTION

Persistent view hierarchy

A stable AppKit host keeps open and close transitions composed, tactile, and ready for high-refresh displays.

03 / MEDIA

Native media controls

Music playback and metadata live inside the launcher, keeping the most common controls close without a separate utility.

04 / CLEANUP

Better uninstall routing

Route supported removals through AppCleaner when available, with a straightforward fallback to the system Trash.

05 / PRIVACY

A private utility shelf

Keep sensitive shortcuts and developer tools in a PIN-protected Vault category instead of exposing everything at once.

06 / DISPLAYS

Display-aware placement

Use connected-screen awareness to keep MiniPad where the work is, whether that is a laptop panel or an external display.

07 / SEARCH

Fast by muscle memory

Type a few characters to narrow the surface instantly, with categories and labels that stay predictable as your app library grows.

08 / FOCUS

Quiet auto-hide

When the launcher is no longer in use, it retreats to the edge instead of covering the workspace you are trying to protect.

09 / CONTROL

One surface, fewer utilities

Keep launching, playback, cleanup, and private shortcuts in one intentional place rather than scattering them across menu-bar extras.

10 / ACCESS

Keyboard-ready interaction

Every important control can be reached with a keyboard, while the handle remains discoverable for pointer and trackpad users.

11 / SYSTEM

Native permission boundaries

Keep sensitive actions explicit and scoped, with the Vault and uninstall flows making their state clear before anything changes.

12 / DETAIL

Designed for repeat use

Compact labels, restrained motion, and remembered preferences make the tenth interaction feel as considered as the first.
